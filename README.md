# Cups ’n Cones — designforslag

Responsivt, statisk mockup. Åbn dist/index.html eller start en HTTP-server i dist.

Design: fløde, bordeaux og pistacie; cafévarme og dessertfokus.

- Skrifttyper: Google Fonts (DM Sans, Playfair Display), med lokale systemfallbacks.

Facebook-sektionen er en statisk designvisning af to reelle opslag. Den er ikke et live-feed. Menuen linker til den eksisterende hjemmeside. Aktuelle åbningstider henvises til Facebook, så mockuppet ikke opfinder tider eller priser. Logoet er et typografisk designforslag.
